1. JTable – Hiển thị dữ liệu dạng bảng

JTable là một trong những component quan trọng khi xây dựng ứng dụng quản lý bằng Java Swing. Nếu JList thường được sử dụng để hiển thị một danh sách, thì JTable phù hợp hơn khi cần hiển thị dữ liệu gồm nhiều dòng và nhiều cột.

┌─────────┬────────────────────┬─────┬───────────────┐
│ Mã SV   │ Họ tên             │ Tuổi│ Ngành         │
├─────────┼────────────────────┼─────┼───────────────┤
│ SV001   │ Nguyễn Văn An      │ 20  │ CNTT          │
│ SV002   │ Trần Thị Bình      │ 21  │ Kế toán       │
│ SV003   │ Lê Văn Cường       │ 20  │ Điện tử       │
└─────────┴────────────────────┴─────┴───────────────┘

Trong các chương trình quản lý sinh viên, sản phẩm, nhân viên..., JTable thường được dùng để hiển thị danh sách dữ liệu và cho phép người dùng chọn một dòng để xem, sửa hoặc xóa.

1.1. Khái niệm JTable

1.1.1. Khái niệm JTable

JTable là component của Java Swing dùng để hiển thị dữ liệu dưới dạng bảng, gồm các hàng (row) và cột (column).

Cấu trúc cơ bản:

                
         Cột      Cột      Cột
          ↓        ↓        ↓
       ┌────────┬────────┬────────┐
       │ Mã SV  │ Họ tên │ Tuổi   │ ← Hàng
       ├────────┼────────┼────────┤
       │ SV001  │ An     │ 20     │
       ├────────┼────────┼────────┤
       │ SV002  │ Bình   │ 21     │
       ├────────┼────────┼────────┤
       │ SV003  │ Cường  │ 20     │
       └────────┴────────┴────────┘
  • Column: cột dữ liệu.
  • Row: dòng dữ liệu.
  • Cell: ô giao nhau giữa một dòng và một cột.

Ví dụ: SV001 là dữ liệu trong một ô.

1.1.2. Vai trò của JTable trong ứng dụng quản lý

Trong ứng dụng quản lý, JTable thường được sử dụng để:

  • Hiển thị danh sách sinh viên.
  • Hiển thị danh sách sản phẩm.
  • Hiển thị danh sách nhân viên.
  • Hiển thị danh sách hóa đơn.
  • Hiển thị kết quả tìm kiếm.
  • Cho phép người dùng chọn một dòng dữ liệu.
  • Kết hợp với form để sửa hoặc xóa dữ liệu.

Ví dụ ứng dụng quản lý sinh viên:

┌────────────────────────────────────────────────────┐
│                 QUẢN LÝ SINH VIÊN                  │
├────────────────────────────────────────────────────┤
│ Mã SV:  [____________]                             │
│ Họ tên: [____________]                             │
│ Tuổi:   [____________]                             │
│                                                    │
│ [Thêm] [Sửa] [Xóa]                                 │
│                                                    │
│ ┌──────────────────────────────────────────────┐   │
│ │ Mã SV │ Họ tên          │ Tuổi │ Ngành       │   │
│ ├───────┼─────────────────┼──────┼─────────────┤   │
│ │ SV001 │ Nguyễn Văn An   │ 20   │ CNTT        │   │
│ │ SV002 │ Trần Thị Bình   │ 21   │ Kế toán     │   │
│ └──────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────┘

Khi người dùng chọn SV002, chương trình có thể lấy dữ liệu dòng đó và đưa lên các ô nhập để chỉnh sửa.

1.1.3. Cấu trúc hàng và cột

Một JTable được tổ chức theo hai chiều:

  • Hàng – Row: Mỗi hàng thường biểu diễn một đối tượng hoặc một bản ghi. Ví dụ: SV001 | Nguyễn Văn An | 20 | CNTT là thông tin của một sinh viên.
  • Cột – Column: Mỗi cột biểu diễn một thuộc tính. Ví dụ: Mã SV, Họ tên, Tuổi, Ngành.
            Column    Column     Column   
              ↓         ↓          ↓
            Mã SV      Họ tên      Tuổi
        │          │           │
Row 0 ──┼──────────┼───────────┼──────────
        │ SV001    │    An     │    20
        │          │           │
Row 1 ──┼──────────┼───────────┼──────────
        │ SV002    │   Bình    │    21

Cell – Ô: Mỗi ô được xác định bởi row + column. Ví dụ: Hàng 0, Cột 1 có thể chứa Nguyễn Văn An.

1.1.4. Model và View trong JTable

Đây là khái niệm quan trọng khi học JTable. JTable chủ yếu đảm nhiệm việc hiển thị dữ liệu, còn dữ liệu được quản lý bởi TableModel.

                 JTable
                   │
                View
                   │
          Hiển thị dữ liệu
                   ↑
                   │
              TableModel
                   │
              Quản lý dữ liệu
  • View: Là phần giao diện mà người dùng nhìn thấy. 
    ┌────────┬──────────────┬──────┐
│ Mã SV  │ Họ tên       │ Tuổi │
├────────┼──────────────┼──────┤
│ SV001  │ Nguyễn An    │ 20   │
└────────┴──────────────┴──────┘
  • Model: Là nơi chứa dữ liệu của bảng. Trong các bài học cơ bản, ta thường sử dụng: DefaultTableModel.

1.2. DefaultTableModel

1.2.1. Khái niệm DefaultTableModel

DefaultTableModel là một lớp có sẵn trong Swing, được sử dụng để quản lý dữ liệu cho JTable.

Model quản lý:

  • Tên cột.
  • Số lượng dòng.
  • Dữ liệu từng ô.
  • Thêm dòng.
  • Xóa dòng.
  • Thay đổi dữ liệu.
DefaultTableModel
│
├── Tên cột
│   ├── Mã SV
│   ├── Họ tên
│   ├── Tuổi
│   └── Ngành
│
└── Dữ liệu
    ├── SV001 | An    | 20 | CNTT
    ├── SV002 | Bình  | 21 | Kế toán
    └── SV003 | Cường | 20 | Điện tử

Sau đó JTable lấy dữ liệu từ Model để hiển thị.

1.2.2. Khởi tạo DefaultTableModel

Import: import javax.swing.table.DefaultTableModel;

Cú pháp:

Cú pháp
DefaultTableModel model = new DefaultTableModel();

Sau khi tạo model, có thể thêm tên cột.

1.2.3. Khai báo tên cột

Có thể khai báo mảng tên cột:

Khai báo tên cột
String[] columns = {
    "Mã SV",
    "Họ tên",
    "Tuổi",
    "Ngành"
};

Sau đó tạo model:

Tạo model
DefaultTableModel model = new DefaultTableModel(columns, 0);
  • columns → tên các cột
  • 0 → số dòng ban đầu

Kết quả lúc này:

┌─────────┬──────────────┬──────┬──────────┐
│ Mã SV   │ Họ tên       │ Tuổi │ Ngành    │
├─────────┼──────────────┼──────┼──────────┤
│         │              │      │          │
└─────────┴──────────────┴──────┴──────────┘

Chưa có dữ liệu.

1.2.4. Tạo JTable từ DefaultTableModel

Cú pháp:

Tạo JTable
JTable table = new JTable(model);

Mối quan hệ:

DefaultTableModel → JTable → Hiển thị thành bảng

Ví dụ:

Ví dụ
String[] columns = {
    "Mã SV",
    "Họ tên",
    "Tuổi",
    "Ngành"
};

DefaultTableModel model = new DefaultTableModel(columns, 0);
JTable table = new JTable(model);

1.2.5. Thêm Model vào JTable

Cách phổ biến nhất là truyền model ngay khi tạo JTable:

Cách 1
JTable table = new JTable(model);

Ngoài ra có thể tạo JTable trước: JTable table = new JTable(); sau đó thiết lập model: table.setModel(model);

Đối với bài học cơ bản, nên ưu tiên cách 1 vì ngắn gọn và dễ hiểu.

1.3. Thiết lập JTable

Sau khi tạo bảng, có thể thiết lập nhiều thuộc tính để bảng dễ sử dụng hơn.

1.3.1. Thiết lập tiêu đề cột

Tên cột được khai báo trong DefaultTableModel:

Tên cột
String[] columns = {
    "Mã SV",
    "Họ tên",
    "Tuổi",
    "Ngành"
};
┌─────────┬────────────────┬──────┬──────────────┐
│ Mã SV   │ Họ tên         │ Tuổi │ Ngành        │
└─────────┴────────────────┴──────┴──────────────┘

1.3.2. Thiết lập chiều rộng cột

Mỗi cột có thể có chiều rộng khác nhau. Ví dụ cột Mã SV ngắn, cột Họ tên dài hơn.

Chiều rộng cột
table.getColumnModel().getColumn(0).setPreferredWidth(80);
table.getColumnModel().getColumn(1).setPreferredWidth(180);
  • getColumn(0) → lấy cột đầu tiên
  • getColumn(1) → lấy cột thứ hai

Lưu ý: chỉ số cột bắt đầu từ 0.

  • Cột 0 → Mã SV
  • Cột 1 → Họ tên
  • Cột 2 → Tuổi
  • Cột 3 → Ngành

1.3.3. Thiết lập chiều cao dòng

Có thể thay đổi chiều cao của các dòng:

Chiều cao dòng
table.setRowHeight(30);

Giá trị 30 là chiều cao dòng tính theo pixel.

1.3.4. Cho phép/không cho phép chỉnh sửa ô

Mặc định, JTable có thể cho phép người dùng chỉnh sửa dữ liệu trực tiếp trong ô tùy theo model. Trong ứng dụng quản lý cơ bản, ta thường muốn: Người dùng chỉ chọn dòng, còn việc sửa dữ liệu được thực hiện thông qua Form và nút Sửa. Khi đó nên không cho phép chỉnh sửa trực tiếp ô.

Không cho phép chỉnh sửa
DefaultTableModel model = new DefaultTableModel(columns, 0) {
    @Override
    public boolean isCellEditable(int row, int column) {
        return false;
    }
};
  • return false; → Không cho phép chỉnh sửa.
  • return true; → Cho phép chỉnh sửa.

1.3.5. Thiết lập chế độ chọn dòng

Có thể cho phép người dùng chọn một dòng:

Chế độ chọn
table.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);

Cần import: import javax.swing.ListSelectionModel;

Điều này rất phù hợp với các thao tác: Sửa, Xóa, Xem chi tiết.

1.3.6. Đặt JTable trong JScrollPane

JTable thường được đặt trong JScrollPane.

JScrollPane
JScrollPane scrollPane = new JScrollPane(table);

Sau đó thêm scrollPane vào giao diện thay vì thêm trực tiếp table.

JScrollPane → JTable

Khi bảng có nhiều dữ liệu, thanh cuộn giúp người dùng xem được toàn bộ dữ liệu.

Lưu ý: model.setRowCount(0); → Xóa các dòng dữ liệu, không xóa tên cột.

1.5. Lấy dữ liệu từ JTable

Trong ứng dụng quản lý, việc lấy dữ liệu từ JTable rất quan trọng. Ví dụ người dùng chọn SV002 | Trần Thị Bình | 21 | Kế toán, chương trình cần lấy dữ liệu đó để: Hiển thị lên Form, Sửa, Xóa, Xem chi tiết.

1.5.1. Lấy dòng đang được chọn

Phương thức: table.getSelectedRow();

Lấy dòng chọn
int row = table.getSelectedRow();

Nếu người dùng chọn dòng thứ 2 (SV002), thì row = 1 (vì chỉ số dòng bắt đầu từ 0).

Dòng hiển thịChỉ số
Dòng 10
Dòng 21
Dòng 32
Dòng 43

1.5.2. Kiểm tra có dòng được chọn hay không

Nếu không có dòng nào được chọn, table.getSelectedRow() sẽ trả về -1.

Kiểm tra
int row = table.getSelectedRow();

if (row == -1) {
    JOptionPane.showMessageDialog(null, "Vui lòng chọn một dòng!");
    return;
}

1.5.3. Lấy giá trị của một ô

Cú pháp: table.getValueAt(row, column);

Trong đó: row – chỉ số dòng, column – chỉ số cột.

Ví dụ:

Ví dụ
Object value = table.getValueAt(1, 1);

Có nghĩa: Dòng 1, Cột 1 → Trần Bình

          0          1              2
       Mã SV      Họ tên          Tuổi
0      SV001      Nguyễn An       20
1      SV002      Trần Bình       21
2      SV003      Lê Cường       20

1.5.4. Chuyển giá trị về String

getValueAt() trả về kiểu Object. Có thể chuyển sang String:

Chuyển sang String
String value = table.getValueAt(row, column).toString();

Ví dụ:

Ví dụ
String maSV = table.getValueAt(row, 0).toString();

Giả sử có: SV001 | Nguyễn Văn An | 20 | CNTT

Sau khi lấy row:

1.6. Sự kiện trên JTable

Khi người dùng thao tác với JTable, chương trình có thể cần phản ứng lại.

Người dùng click vào một dòng
             ↓
       Chương trình nhận sự kiện
             ↓
       Xác định dòng được chọn
             ↓
       Lấy dữ liệu
             ↓
       Hiển thị lên Form

Có hai hướng thường gặp: MouseListener và ListSelectionListener. Trong phần này tập trung vào MouseListener và sự kiện chọn dòng.

1.6.1. MouseListener

MouseListener dùng để xử lý các thao tác chuột như: Nhấn chuột, Nhả chuột, Click chuột, Chuột đi vào component, Chuột rời component.

Cần import: import java.awt.event.MouseListener;

MouseListener
table.addMouseListener(new MouseAdapter() {
    @Override
    public void mouseClicked(MouseEvent e) {
        // Xử lý khi click JTable
    }
});

Cần import: import java.awt.event.MouseAdapter; và import java.awt.event.MouseEvent;

1.6.2. Sự kiện chọn dòng

Ví dụ khi click vào dòng:

Ví dụ
table.addMouseListener(new MouseAdapter() {
    @Override
    public void mouseClicked(MouseEvent e) {
        int row = table.getSelectedRow();
        System.out.println(row);
    }
});
  • Click dòng đầu tiên → row = 0
  • Click dòng thứ hai → row = 1

1.6.3. Hiển thị dữ liệu dòng được chọn lên Form

Đây là ví dụ quan trọng nhất của phần JTable.

Giả sử Form có: Mã SV, Họ tên, Tuổi. Bảng hiển thị danh sách sinh viên. Khi click vào một dòng, Form sẽ hiển thị dữ liệu của dòng đó.

Hiển thị lên Form
table.addMouseListener(new MouseAdapter() {
    @Override
    public void mouseClicked(MouseEvent e) {
        int row = table.getSelectedRow();

        if (row != -1) {
            txtMaSV.setText(table.getValueAt(row, 0).toString());
            txtHoTen.setText(table.getValueAt(row, 1).toString());
            txtTuoi.setText(table.getValueAt(row, 2).toString());
        }
    }
});

1.6.4. Phân tích ví dụ

Khi người dùng click: SV002 | Trần Thị Bình | 21

  • Bước 1: Lấy dòng: int row = table.getSelectedRow(); → row = 1
  • Bước 2: Lấy mã: table.getValueAt(1, 0) → SV002
  • Bước 3: Lấy họ tên: table.getValueAt(1, 1) → Trần Thị Bình
  • Bước 4: Lấy tuổi: table.getValueAt(1, 2) → 21
  • Bước 5: Đưa lên Form: Mã SV: SV002, Họ tên: Trần Thị Bình, Tuổi: 21

1.6.5. Mối quan hệ giữa JTable và Form

Trong chương trình quản lý, mô hình thường là:

                 JTable
                   │
             Chọn một dòng
                   ↓
             getSelectedRow()
                   ↓
              getValueAt()
                   ↓
             Lấy dữ liệu
                   ↓
              JTextField

Ngược lại khi thêm dữ liệu:

             JTextField
                  │
             getText()
                  ↓
          Kiểm tra dữ liệu
                  ↓
           DefaultTableModel
                  ↓
              addRow()
                  ↓
                JTable

Đây là mô hình rất quan trọng để học viên hiểu cách xây dựng ứng dụng quản lý.

2.6. Kiểm tra dữ liệu

Kiểm tra dữ liệu là phần rất quan trọng trong chương trình quản lý.

Không nên để người dùng nhập:

Mã SV:       [              ]
Họ tên:      [              ]
Tuổi:        [abc           ]

hoặc:

Mã SV:       SV001
Mã SV:       SV001   (bị trùng)

2.6.1. Kiểm tra dữ liệu rỗng

Cách cơ bản:

Kiểm tra rỗng
if (value.trim().isEmpty()) {
    JOptionPane.showMessageDialog(this, "Dữ liệu không được để trống!");
    return;
}

Có thể kiểm tra nhiều trường:

Nhiều trường
if (maSV.isEmpty() || hoTen.isEmpty() || tuoiText.isEmpty()) {
    JOptionPane.showMessageDialog(this, "Vui lòng nhập đầy đủ thông tin!");
    return;
}

2.6.2. Kiểm tra mã không trùng

Trước khi thêm SV001 cần kiểm tra xem SV001 đã tồn tại chưa.

Cách duyệt bảng:

Kiểm tra trùng
for (int i = 0; i < model.getRowCount(); i++) {
    String ma = model.getValueAt(i, 0).toString();
    if (ma.equalsIgnoreCase(maSV)) {
        JOptionPane.showMessageDialog(this, "Mã sinh viên đã tồn tại!");
        return;
    }
}

equalsIgnoreCase() cho phép so sánh không phân biệt chữ hoa/chữ thường. Ví dụ: SV001, sv001, Sv001 đều được xem là cùng một mã.

2.6.3. Kiểm tra định dạng dữ liệu

Có thể yêu cầu: Mã SV có dạng SV001, SV002, SV003...

Ví dụ sử dụng biểu thức chính quy:

Định dạng
if (!maSV.matches("SV\\d{3}")) {
    JOptionPane.showMessageDialog(this, "Mã SV phải có dạng SV001!");
    return;
}
  • SV là hai ký tự cố định.
  • \\d đại diện cho một chữ số.
  • {3} yêu cầu 3 chữ số.

Do đó: SV001 → hợp lệ, SV123 → hợp lệ, SV1 → không hợp lệ, ABC01 → không hợp lệ.

2.6.4. Kiểm tra dữ liệu số

Ví dụ tuổi phải là số:

Kiểm tra số
int tuoi;
try {
    tuoi = Integer.parseInt(tuoiText);
} catch (NumberFormatException e) {
    JOptionPane.showMessageDialog(this, "Tuổi phải là số nguyên!");
    return;
}

Có thể kiểm tra thêm phạm vi:

Phạm vi
if (tuoi < 16 || tuoi > 100) {
    JOptionPane.showMessageDialog(this, "Tuổi không hợp lệ!");
    return;
}
  • 20 → hợp lệ
  • 21 → hợp lệ
  • abc → không hợp lệ
  • -5 → không hợp lệ
  • 150 → không hợp lệ

2.6.5. Thông báo lỗi bằng JOptionPane

Các lỗi nhập dữ liệu nên được thông báo rõ ràng.

Thông báo
JOptionPane.showMessageDialog(this, "Mã sinh viên không được để trống!");

Một số thông báo nên sử dụng:

  • "Mã sinh viên không được để trống!"
  • "Họ tên không được để trống!"
  • "Tuổi phải là số!"
  • "Tuổi không hợp lệ!"
  • "Mã sinh viên đã tồn tại!"
  • "Vui lòng chọn một dòng!"
  • "Dữ liệu đã được thêm thành công!"

Thông báo tốt cần cho người dùng biết: Lỗi ở đâu và cần sửa như thế nào.

2.6.6. Xây dựng hàm kiểm tra dữ liệu

Thay vì viết lại nhiều lần, có thể tạo một phương thức riêng:

Hàm kiểm tra
private boolean kiemTraDuLieu() {
    String maSV = txtMaSV.getText().trim();
    String hoTen = txtHoTen.getText().trim();
    String tuoiText = txtTuoi.getText().trim();

    if (maSV.isEmpty()) {
        JOptionPane.showMessageDialog(this, "Mã SV không được để trống!");
        txtMaSV.requestFocus();
        return false;
    }

    if (hoTen.isEmpty()) {
        JOptionPane.showMessageDialog(this, "Họ tên không được để trống!");
        txtHoTen.requestFocus();
        return false;
    }

    if (tuoiText.isEmpty()) {
        JOptionPane.showMessageDialog(this, "Tuổi không được để trống!");
        txtTuoi.requestFocus();
        return false;
    }

    try {
        int tuoi = Integer.parseInt(tuoiText);
        if (tuoi < 16 || tuoi > 100) {
            JOptionPane.showMessageDialog(this, "Tuổi không hợp lệ!");
            return false;
        }
    } catch (NumberFormatException e) {
        JOptionPane.showMessageDialog(this, "Tuổi phải là số!");
        return false;
    }

    return true;
}

Sau đó khi thêm:

Sử dụng
if (!kiemTraDuLieu()) {
    return;
}

Khi sửa cũng có thể sử dụng: if (!kiemTraDuLieu()) { return; }

  • Xây dựng cửa sổ nhập liệu riêng bằng JDialog.

4.1. ArrayList

4.1.1. Khái niệm ArrayList

ArrayList là một lớp trong Java dùng để lưu trữ danh sách các phần tử.

Khác với mảng thông thường, ArrayList có thể tăng hoặc giảm kích thước trong quá trình chạy chương trình.

ArrayList
┌────────┬────────┬────────┬────────┐
│ SV001  │ SV002  │ SV003  │ SV004  │
└────────┴────────┴────────┴────────┘

Có thể thêm: SV001 → SV002 → SV003 → SV004 → SV005

Hoặc xóa: SV001 → SV002 → SV004 → SV005

Trong chương trình quản lý sinh viên, ta có thể sử dụng: ArrayList<SinhVien> để lưu danh sách sinh viên.

  • danhSachSinhVien → Tên ArrayList

Khi chương trình còn nhỏ, học viên có thể viết giao diện, dữ liệu và xử lý sự kiện trong cùng một class. Tuy nhiên, khi chương trình có nhiều chức năng như Thêm – Sửa – Xóa – Tìm kiếm – Hiển thị dữ liệu, việc viết tất cả trong một class sẽ khiến chương trình khó đọc, khó sửa và khó mở rộng.

Ví dụ một chương trình quản lý sinh viên có thể chứa:

  • Class sinh viên.
  • Danh sách sinh viên.
  • Giao diện nhập liệu.
  • Giao diện bảng.
  • Nút Thêm, Sửa, Xóa, Tìm kiếm.
  • Xử lý sự kiện.
  • Kiểm tra dữ liệu.

Nếu tất cả được đặt trong một class:

MainFrame.java
├── Thuộc tính dữ liệu
├── ArrayList
├── JTextField
├── JButton
├── JTable
├── Xử lý thêm
├── Xử lý sửa
├── Xử lý xóa
├── Xử lý tìm kiếm
├── Kiểm tra dữ liệu
└── Hiển thị bảng

class sẽ rất dài và khó quản lý.

Vì vậy, cần tổ chức chương trình thành các thành phần riêng:

Model → Dữ liệu + xử lý dữ liệu
View → Giao diện
Controller → Xử lý sự kiện + điều phối

Đây là cơ sở để học viên làm quen với mô hình MVC.

5.4. Controller

5.4.1. Khái niệm Controller

Controller là thành phần đứng giữa View và Model.

Nhiệm vụ chính:

  • Nhận thao tác từ người dùng.
  • Xử lý sự kiện.
  • Lấy dữ liệu từ View.
  • Gọi Model xử lý.
  • Yêu cầu View cập nhật giao diện.
Người dùng → View → Controller → Model
Sau khi Model xử lý: Model → Controller → View → Hiển thị kết quả

5.5. Giới thiệu mô hình MVC

5.5.1. MVC là gì?

MVC là viết tắt của: M = Model, V = View, C = Controller

Đây là cách tổ chức chương trình thành ba thành phần có trách nhiệm khác nhau.

             Controller
             ↙         ↘
           View  ←──→  Model
Model → Dữ liệu
View → Giao diện
Controller → Điều phối

5.5.2. Model

Model phụ trách: Dữ liệu, Đối tượng, Danh sách, Thêm, Sửa, Xóa, Tìm kiếm.

Ví dụ: SinhVien, SinhVienModel, ArrayList<SinhVien>

5.5.3. View

View phụ trách: Giao diện, Nhập dữ liệu, Hiển thị dữ liệu, Các component Swing.

Ví dụ: SinhVienFrame, JTextField, JButton, JComboBox, JTable

5.5.4. Controller

Controller phụ trách: Xử lý sự kiện, Nhận yêu cầu, Lấy dữ liệu từ View, Gọi Model, Cập nhật View.

Nhấn JButton "Thêm" → Controller → Lấy dữ liệu View → Tạo SinhVien → Model.them() → Cập nhật View

5.5.5. Ví dụ quy trình thêm sinh viên theo MVC

Giả sử người dùng nhập: Mã SV: SV001, Họ tên: Nguyễn Văn An, Lớp: CNTT1 và nhấn [THÊM]

Bước 1 – View: Người dùng thao tác trên giao diện. JTextField, JButton

Bước 2 – Controller: Controller nhận sự kiện. ActionListener → Controller

Bước 3 – Controller lấy dữ liệu: View → getMaSV(), getHoTen(), getLop()

Bước 4 – Controller tạo Object: SinhVien sv

Bước 5 – Model lưu dữ liệu: model.them(sv) → ArrayList.add(sv)

Bước 6 – View cập nhật: ArrayList → JTable

├────────┼──────────────────┼────────┤

5.5.6. Ví dụ quy trình xóa theo MVC

Người dùng chọn dòng SV002 và nhấn Xóa.

Người dùng → View → Controller → Lấy dòng được chọn → index = 1 → Model → ArrayList.remove(1) → Controller → View → JTable

Điểm quan trọng: Controller là thành phần điều phối, chứ không phải nơi lưu dữ liệu.

5.5.7. Lợi ích của MVC

1. Dễ đọc

Mỗi class có nhiệm vụ rõ ràng.

2. Dễ sửa

Ví dụ muốn thay đổi giao diện: View không nhất thiết phải sửa toàn bộ Model.

3. Dễ mở rộng

Có thể thêm: Tìm kiếm, Sắp xếp, Thống kê, Xuất dữ liệu mà không làm chương trình trở nên quá rối.

4. Dễ bảo trì

Khi có lỗi, có thể xác định lỗi thuộc: Model, View, Controller.

5. Tái sử dụng

Một Model có thể được sử dụng bởi nhiều giao diện khác nhau.

        ├── xử lý xóa
        └── xử lý tìm kiếm

5.10. Bài tập tổng hợp

Bài tập: Tách chương trình quản lý sinh viên theo MVC

Sử dụng chương trình quản lý sinh viên đã xây dựng ở phần trước và tổ chức lại thành: model, view, controller

Yêu cầu 1 – Model

Tạo: SinhVien.java và SinhVienModel.java

SinhVien gồm: Mã sinh viên, Họ tên, Giới tính, Năm sinh, Lớp.

SinhVienModel quản lý: ArrayList<SinhVien>, Thêm, Sửa, Xóa, Tìm kiếm.

Yêu cầu 2 – View

Tạo: MainFrame.java và SinhVienFrame.java

Giao diện gồm: JTextField, JRadioButton, JComboBox, JButton, JTable, JScrollPane.

Yêu cầu 3 – Controller

Tạo: SinhVienController.java

Xử lý: Sự kiện nút Thêm, Sự kiện nút Sửa, Sự kiện nút Xóa, Sự kiện Tìm kiếm, Chọn dòng trên JTable, Kiểm tra dữ liệu.

Yêu cầu 4 – Hoàn thiện luồng MVC

Chức năng Thêm:

Form → Controller → SinhVien Object → Model → ArrayList → Controller → View → JTable

Chức năng Sửa:

JTable → Controller → Model → SinhVien → Cập nhật → JTable

Chức năng Xóa:

JTable → Controller → Model.remove() → ArrayList → JTable

Kết quả cần đạt

Sau phần này, học viên cần phân biệt được rõ:

SinhVien.java → "Dữ liệu của một sinh viên là gì?"
SinhVienModel.java → "Danh sách sinh viên được quản lý như thế nào?"
SinhVienFrame.java → "Giao diện hiển thị như thế nào?"
SinhVienController.java → "Khi người dùng thao tác thì chương trình làm gì?"

Và hiểu được kiến trúc tổng thể:

                 ┌─────────────┐
                 │    VIEW     │
                 │ Giao diện   │
                 └──────┬──────┘
                        │
                        ↓
                 ┌─────────────┐
                 │ CONTROLLER  │
                 │ Điều phối   │
                 └──────┬──────┘
                        │
                        ↓
                 ┌─────────────┐
                 │    MODEL    │
                 │ Dữ liệu     │
                 │ Xử lý       │
                 └─────────────┘

Ghi nhớ trọng tâm: Tổ chức chương trình theo mô hình MVC giúp tách biệt dữ liệu (Model), giao diện (View) và xử lý (Controller). Điều này làm cho chương trình dễ đọc, dễ bảo trì và dễ mở rộng. Model quản lý dữ liệu, View hiển thị giao diện, Controller điều phối giữa Model và View. Khi chương trình phát triển, việc tổ chức code theo MVC là một kỹ năng quan trọng giúp duy trì chất lượng và khả năng mở rộng của phần mềm.
